Privacy policy

Effective November 23, 2026. Applies to the Cedar website and to "shorts-uploader", the Google OAuth app that Cedar uses to manage its own YouTube channel.

Summary

  • shorts-uploader is a private tool. Cedar's owner uses it only with Cedar's own YouTube channel. It is not offered to the public.
  • It uploads Cedar's own videos as private and reads Cedar's own channel statistics. The app's code always uploads as private, and making a video public is done by a person in YouTube Studio. Its permissions don't allow deleting or editing videos, or posting comments.
  • Nothing is sold, shared for advertising, or sent to any server we run. We don't run any servers.
  • This website uses no cookies, no analytics, and no tracking.

Google permissions the app uses

Permission (scope)What it's used for
https://www.googleapis.com/auth/youtube.uploadUploading finished Cedar videos, with their title, description and tags, to Cedar's channel. Every upload is set to private. A person publishes videos manually in YouTube Studio.
https://www.googleapis.com/auth/youtube.readonlyReading Cedar's channel name and statistics, the list of uploaded videos, and each video's public counts (views, likes, comments). This confirms uploads went to the right channel and tracks performance.
https://www.googleapis.com/auth/yt-analytics.readonlyReading aggregate YouTube Analytics reports for Cedar's own videos: views, watch time, average view duration, percentage viewed, likes, shares, subscribers gained, and traffic source totals. These reports are anonymous totals. They identify no individual viewer.

The app asks for no other Google permissions: no Gmail, Drive, Contacts, or account management.

What data is handled

  • Sent to Google: Cedar's own video files and their metadata, when they are uploaded to YouTube.
  • Received from Google: Cedar's channel information, video list, public video counts, and aggregate analytics totals, as described above.
  • Sign-in credentials: the OAuth access and refresh tokens Google issues after the channel owner approves access. Passwords are never seen or stored. Google handles sign-in.
  • Viewer data: none. The app receives no names, emails, comments, or other personal information about viewers.

How data is used

The data is used only to operate Cedar's channel: uploading Cedar's videos, confirming that uploads succeeded, and studying aggregate performance to decide which topics and formats to make next. The channel owner uses AI tools, including Anthropic's Claude, to help run the production scripts and review those aggregate statistics. Only Cedar's own channel totals are processed this way, never viewer personal data.

Storage and security

  • OAuth tokens are stored only in one file on the channel owner's own computer. The file is readable only by that computer's user account. They are not uploaded, published, or shared.
  • Statistics snapshots (aggregate numbers only) are saved as files on the same computer to track performance over time.
  • No database, cloud server, or third-party storage is used.

Sharing

We don't sell, rent, or share data from Google APIs with anyone, and we don't use it for advertising. The only exchange of data is with Google itself, through the YouTube APIs.

Google API Services User Data Policy

shorts-uploader's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube data is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Retention and deletion

Tokens are kept only while the app needs access. They stop working as soon as access is revoked, and the token file can be deleted from the computer at any time. Statistics snapshots are kept to compare performance over time and can be deleted at any time. Videos uploaded to YouTube stay on YouTube until they are deleted there.

How to revoke access

  1. Open myaccount.google.com/permissions while signed in to the Google account that owns the channel.
  2. Choose shorts-uploader and select Remove access. The app immediately loses all access.
  3. Optionally, delete the token file from the computer where the app runs.

Watching Cedar on YouTube

If you watch Cedar's videos, YouTube's own privacy policy applies to that viewing. Cedar can't see who you are.

Changes

If the app's permissions or data use change, this page will be updated before the change takes effect, with a new effective date.
